
# PICKA'S HUB

**A Roblox Script Hub by Picka.**

PICKA'S HUB is a Lua/Luau project focused on a custom interface, modular scripts, and multiple icon libraries for building organized user interfaces.

## Features

- Custom UI components
- Modular Lua/Luau structure
- Multiple icon libraries
- Reusable icon lookup functions
- Organized source files
- Ongoing development and improvements

## Icon Libraries

| Library | File |
| --- | --- |
| Gravity | `Icons/dist/gravity.lua` |
| Lucide | `Icons/dist/lucide.lua` |
| SF Symbols | `Icons/dist/sfsymbols.lua` |
| Solar | `Icons/dist/solar.lua` |
